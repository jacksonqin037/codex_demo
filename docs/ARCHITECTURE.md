# 场景、模型与仪器扩展

## 数据流

自然语言 → 本地解析器/可选远程规划器 → validateScene → 参数控件与设备布局 → advance/readings → SVG指针、数值与曲线。

场景规划只能选择已经注册且通过验证的模型。开放式文本不能凭空保证实验方程和仪器结构正确，因此不允许直接执行模型返回的 JavaScript 或 HTML。

## 结构化场景 v1

```json
{
  "version": 1,
  "model": "rc",
  "title": "RC充放电实验",
  "parameters": {"voltage":12,"resistance":1000,"capacitance":1000},
  "instruments": ["voltmeter","ammeter","oscilloscope"]
}
```

模型 ID 为 ohm、rc、spring。参数单位由 engine.mjs 固定，电容使用 μF。仪表必须属于该模型白名单。所有量程、读数映射由注册表定义，指针映射采用线性刻度，超量程时停止在刻度端点并显示提示。示波器展示第一观测量最近12秒随时间的曲线，为软件采集示意。

## 可选语言模型规划接口

服务器对 SCENE_PLANNER_URL 发起 POST：

```json
{"description":"用户描述","schemaVersion":1,"allowedModels":["ohm","rc","spring"]}
```

规划服务应返回上述场景 JSON 原文。可用任意语言模型实现这一服务；此仓库未绑定模型供应商、未配置付费调用，也未验证真实远程服务。若设置 SCENE_PLANNER_TOKEN，服务器在 Authorization: Bearer 中发送它。规划服务错误会显示给用户，不会悄悄降级成另一个实验。服务端超时20秒；前端25秒。应用对所有返回场景再次校验。

## 新增实验与真实仪器

1. 取得实验定义、边界条件、单位与相关设备的官方手册；明确是教学示意还是真实型号复刻。
2. 在 presets 中注册参数范围、默认值、观测量、兼容仪器。
3. 实现 initialState、advance、readings，并用解析解、参考数据或守恒关系验证。
4. 添加本地描述识别规则，或让远程规划器选择新模型。
5. 在仪器库注册端子、量程、刻度、读数与操作状态；使用 SVG 分层组件实现动态部分。
6. 在 drawStage 中添加装置连接图与事件，确保电压表并联、电流表串联，位置与物理量对应。
7. 补充数值/解析测试和浏览器操作检查，不接受只修改界面标签。

真实仪表照片可做背景素材，但指针、开关、量程等必须为独立可交互图层。任意文本生成任意学科实验需要持续扩充经过验证的模型与仪器库。

## 当前模型约束

- 欧姆定律采用理想直流稳态，电源内阻、仪表负载与温升忽略。
- RC采用精确指数离散更新，电容电压保持连续；断开开关表示理想隔离，暂停表示仿真时间停止。
- 弹簧采用水平线性模型，黏性阻尼，半隐式积分，内部步长不超过1ms。
- 调整弹簧初始位移会立即重新设置位置与速度；改变其他参数保留当前状态。
- 调整参数可能引入外部能量，这是参数实验的设定，不宣称整个操作过程能量守恒。
- CSV记录当前时间、参数、观测量；切换场景清空记录，重置时间保留记录。当前版本没有数据库持久化。
